# eBPF 开发者教程的网络搭建

在本教程中，我们将搭建一个简单的网络拓扑，用 eBPF/XDP（Express Data Path）模拟一个负载均衡器。该环境包括一台本地机器、一个负载均衡器（可以由 XDP 程序增强），以及两台后端服务器（`h2` 和 `h3`）。本地机器把数据包路由到负载均衡器，再由负载均衡器在两台后端服务器之间分发流量。

# 简单的 XDP 负载均衡器教程

本教程将指导你搭建一个简单的虚拟网络，使用 eBPF/XDP 模拟一个负载均衡器。

## 网络拓扑

```txt
   +------------------+
   |   本地机器        |
   |  IP: 10.0.0.1    |
   +--------+---------+
            |
   +--------+---------+
   |   负载均衡器      |
   |  IP: 10.0.0.10   |
   +--------+---------+
            |
    +-------+-------+
    |               |
+---+---+       +---+---+
|  h2   |       |  h3   |
|10.0.0.2|       |10.0.0.3|
+-------+       +-------+
```

- **本地机器**：模拟发送流量的客户端（`10.0.0.1`）。
- **负载均衡器**：把流量分发到后端服务器（`10.0.0.10`）。
- **h2** 和 **h3**：模拟两台后端服务器（`10.0.0.2` 和 `10.0.0.3`）。

### 搭建步骤

下面的脚本会创建虚拟网络命名空间，并为本地机器、负载均衡器和后端服务器配置 IP 地址。

```bash
sudo ./setup.sh
```

测试完成后清理环境：

```bash
sudo ./teardown.sh
```

### 测试网络连通性

可以使用 `ping` 命令测试网络连通：

在两台后端服务器之间 ping（`h2` 到 `h3`）

```bash
sudo ip netns exec h2 ping -c 3 10.0.0.3
```

从后端服务器（`h2`）ping 负载均衡器

```bash
sudo ip netns exec h2 ping -c 3 10.0.0.10
```

从本地机器 ping 负载均衡器

```bash
ping -c 3 10.0.0.10
```

就是这样！通过这个简单环境，你可以模拟一个使用 eBPF/XDP 的负载均衡器。你还可以编写自定义的 XDP 程序来控制 `h2` 和 `h3` 之间的流量分发方式，从而扩展该环境。
